# 标签 / 元数据与语义字段的边界

Type: grilling
Blocked by:

## Question

**"标签"要不要看？它和"语义字段"怎么划界？**

具体指：

- MP4 的 `udta` → `meta` → `ilst`（iTunes 风格的 tag：标题、艺术家、专辑、封面）
- FLAC 的 Vorbis Comment
- MP3 的 ID3v2 / ID3v1
- Matroska 的 Tags 元素

要定的：

- 这些**要不要进 MVP**？如果进，进到哪个视图——跟解码出来的字段平级放在语义字段视图里，还是单独一个"标签"区段？
- **概念边界怎么划**：`GLOSSARY.md` 已经把"元数据 / Metadata"列为"语义字段"的 avoid 词，意思是"语义字段"专指从容器结构里**解读**出来的技术属性（时长、采样率）。那"标签"是一个**第三个类别**（作者写进文件的元数据），还是"语义字段"的一个子集？**"语义字段"这个词本身要不要重新命名或扩义**，以容纳标签？
- 顺带：文件级的技术属性（如时长）算"语义字段"，那容器级的技术属性（如 `ftyp` 的 brand、movie timescale）呢？它既不是标签，也不是轨道属性——它落在哪？

**产出**：类别的边界定义（大概率要改 `GLOSSARY.md`）+ 标签在 MVP 里的去留决定。

**注意**：这票是**术语层面**的决定，会影响 `GLOSSARY.md`、票 08 的词表、以及规格里界面区域的划分。先定词，再定表。
