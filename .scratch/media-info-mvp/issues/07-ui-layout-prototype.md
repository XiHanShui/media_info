# 界面布局与多文件交互

Type: prototype
Status: resolved
Blocked by:

## Question

界面到底长什么样？语义字段与结构树并排的时候，用哪种布局？多标签页和文件列表怎么组织？hex 侧栏放哪？

要原型出来对比的候选：

- **左右分栏**：左边语义字段，右边结构树
- **上下分栏**：语义字段在上，结构树在下
- **Tab 切换**：字段一个页签、结构树一个页签
- 以及 hex 侧栏的落位（跟在结构树右边？做成结构树的第三栏？双击块才弹出？）

还要原型出多标签页的形态：

- 标签栏 + 每个标签一个文件？还是文件列表 + 右侧预览？
- 未解析 / 解析中 / 解析失败分别长什么样？

**做法**：在一条 throwaway 路由上，同一路由用参数切换上述几种变体，让用户直接挑。

**产出**：选定的布局 + 交互要点（能直接写进规格的那种粒度）。

**注意**：本票**不依赖**[统一节点模型与双视图的数据来源](01-unified-node-model.md)——用 mock 数据做原型即可。原型里出现的字段名要按[统一语义字段词表](08-field-vocabulary.md) 的词表风格占位（英文技术名），但别在[统一语义字段词表](08-field-vocabulary.md) 之前把词表定死。

## Answer

**左右分栏。** 定下来的细节：

- **顶层**：标签页栏（每个标签 = 一个打开的文件，右侧有关闭按钮）+ 工具条（打开文件 / 导出 JSON）。
- **主体**：左右两栏。
  - **左栏 = 语义字段视图**：三个区段，顺序为「文件级」→「轨道级」（每条轨道一组）→「标签」。区段之间用分隔线，不折叠。
  - **右栏 = 结构树视图**：可展开的块树，每行显示 `type` + `offset` + `size`。
- **hex 面板在右栏下方展开**（选中块时出现，可折叠）。面板标题显示该块的 `type`、offset、size；内容是 hex + ASCII 侧栏。
- **选中块时该块在树里高亮**，hex 面板随之更新。
- **解析中**：两栏显示占位/进度态；**解析失败**：显示错误信息（可展开详情），已读到的部分结构仍展示（对应 user story 49）。
- **多标签页**：`Ctrl+Tab` 在标签间切换；关闭标签不影响其它标签。
- 结构树条目极多时用**虚拟滚动**，保证流畅（对应 user story 23）。
