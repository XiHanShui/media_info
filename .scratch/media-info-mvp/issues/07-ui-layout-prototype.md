# 界面布局与多文件交互

Type: prototype
Blocked by:

## Question

界面到底长什么样？语义字段与结构树并排的时候，用哪种布局？多标签页和文件列表怎么组织？hex 侧栏放哪？

要原型出来对比的候选：

- **左右分栏**：左边语义字段，右边结构树
- **上下分栏**：语义字段在上，结构树在下
- **Tab 切换**：字段一个页签、结构树一个页签
- 以及 hex 侧栏的落位（跟在结构树右边？做成结构树的第三栏？双击块才弹出？）

还要原型出多标签页的形态：

- 标签栏 + 每个标签一个文件？还是文件列表 + 右侧预览？
- 未解析 / 解析中 / 解析失败分别长什么样？

**做法**：在一条 throwaway 路由上，同一路由用参数切换上述几种变体，让用户直接挑。

**产出**：选定的布局 + 交互要点（能直接写进规格的那种粒度）。

**注意**：本票**不依赖**票 01——用 mock 数据做原型即可。原型里出现的字段名要按票 08 的词表风格占位（英文技术名），但别在票 08 之前把词表定死。
