# 视觉语言

> 这个界面的目标是**技术仪器**，不是消费级应用。定位参考物：调色台、示波器、十六进制编辑器、010 Editor。
> 配色与字体的具体值都写在 `lib/src/app/theme.dart`，**代码里一律用那里的常量，不要就地写死颜色**。

## 配色（`MediaColors`）

| 名称 | 值 | 用途 |
|---|---|---|
| `ink` | `#0E1116` | 底色。偏蓝的石墨灰，**不是纯黑**——纯黑会让边界糊在一起 |
| `panel` | `#161A21` | 面板底色 |
| `panelHigh` | `#1C212A` | 悬停/选中行 |
| `edge` | `#252B35` | 发丝分隔线（1px） |
| `edgeSoft` | `#1B2029` | 更弱的行内分组线 |
| `chalk` | `#E4E1DA` | 主文字。暖白，像胶片片基 |
| `chalkDim` | `#9BA1AC` | 次要文字（字段显示名、区段眉标） |
| `chalkFaint` | `#616875` | 三级文字（英文技术名、单位、注记） |
| `amber` | `#E8A33D` | **唯一的强调色**。胶片引导片 / 钨丝灯。只用在真正需要看的地方 |
| `amberDeep` | `#8C6220` | 强调色暗调（胶片条上的媒体载荷段） |
| `teal` | `#5FA8A0` | 坐标与结构色。偏移量、块类型、层级、标签 key |
| `tealDeep` | `#2E5551` | 坐标色暗调（胶片条上的元数据段） |
| `rose` | `#D96A6A` | 警告：截断、损坏、扩展名不符 |
| `violet` | `#9189C9` | 推算值（我们自己算的，不是文件里写的） |

**颜色的用法是编码，不是装饰**：

- 琥珀 = 媒体载荷（`mdat`）——真正的音视频数据
- 青 = 结构与坐标——`moov`/`ftyp`/`meta`、偏移量、块类型、标签 key
- 紫 = 推算值
- 玫红 = 出问题的地方

除这四种之外，界面里**不出现别的彩色**。灰色系（chalk 三级 + edge）承担其余一切。

## 字体（`MediaType`）

**数据一律等宽，界面文字用无衬线。** 这是整个排版个性的一半——一个二进制检视工具如果连偏移量都用比例字体，就不像是工具。

- 等宽栈：`Cascadia Mono → Consolas → SF Mono → Menlo → DejaVu Sans Mono → monospace`
- 无衬线栈：`Segoe UI → SF Pro Text → Helvetica Neue → Microsoft YaHei UI → system-ui`

不打包字体文件：跨 Windows 与 macOS 的桌面工具，系统字体栈最稳，而且个性来自**等宽/无衬线的二分**与字距，不来自某一款字。

字级：

| 样式 | 用途 | 规格 |
|---|---|---|
| `eyebrow` | 区段眉标（「文件级」「轨道级」「标签」） | 无衬线 10.5px / w600 / **字距 1.8** —— 仪器面板上的丝印字 |
| `label` | 字段中文显示名 | 无衬线 13px |
| `value` | 字段值 | 等宽 13px / w500 / **等宽数字** |
| `note` | 英文技术名、单位、注记 | 等宽 10.5px |
| `blockName` | 结构树的块类型名 | 等宽 12.5px / w500 |
| `coordinate` | 结构树的偏移量/长度列 | 等宽 11.5px / 等宽数字 |

## 布局

```
┌───────────────────────────────────────────────────────────────────────┐
│ ▍media_info   [tab][tab]              [打开文件] [导出 JSON]          │  app bar
├───────────────────────────────────────────────────────────────────────┤
│ ▐██▐▐▐▐▐▐▐▐████████████▐▐  ← 胶片条（顶层块按比例）                  │
├────────────────────────┬──────────────────────────────────────────────┤
│ ▎文件级                 │  结构                    偏移      长度       │
│  时长  duration   1.000s│ ▾ ftyp       isom            0        28      │
│  采样率 sample_rate 44100│  ▾ moov                    28     11162     │
│ ▎轨道 0 ────────────────│    ▸ trak                  32      9000     │
│  编码标识 codec    avc1  │    ▸ mdat               11190       468     │
│ ▎标签                   ├──────────────────────────────────────────────┤
│  ©nam  Song        …    │  00000028  00 00 00 20 66 74 79 70  |..ftyp| │  hex
└────────────────────────┴──────────────────────────────────────────────┘
```

- 左栏 = 语义字段（文件级 / 轨道级 / 标签），宽约 1/3。
- 右栏 = 结构树 + hex 面板，树在上、hex 在下。
- 树有**坐标列**（偏移量、长度），像十六进制编辑器的地址列——右对齐、等宽数字。
- hex 面板是三列经典布局：地址 | 十六进制 | ASCII。

## 签名元素：胶片条（`FileStrip`）

工具条下方一条 34px 的横带，顶层块按各自长度**按比例**排开——像一卷胶片上的画格。

- 段的位置 = 块在文件里的**真实位置**（按累计偏移算，不是按顺序等分）
- 段宽 = 块长 / 文件总长
- 段色 = 块的角色（琥珀=媒体载荷，青=元数据，暗灰=填充/未知）
- 选中的块高亮（琥珀描边 + 提亮）
- 段足够宽时在段内写块类型名；悬停显示「类型 · 偏移 · 长度」

它同时回答两件事：**哪块最占地方**、**选中的东西在文件的哪儿**。MediaInfo 给你字段却丢掉了坐标系，这里把两者合成一张图——这是本工具相对 MediaInfo 的立身之本。

## 交互约定

- **右键复制**字段值（已实现）：值复制时不含单位；时长格式化成 `HH:MM:SS.mmm`。
- **悬停**行时给一点底色（`panelHigh`），长列表好扫读。
- **推算值**带一个紫色「（推算）」chip——用 chip 不用斜体，斜体在等宽小字上几乎看不出来。
- 展开/折叠用 100–150ms 的缓动，不要弹跳、不要花哨转场。
- 尊重系统的"减少动态效果"设置。

## 不要做的事

- 不要用 Material 的阴影与 elevation——这套语言是**发丝线 + 平面色块**。
- 不要用大圆角（超过 4px）——仪器面板没有圆角。
- 不要用渐变、玻璃拟态、彩色阴影。
- 不要把中文显示名换成英文，也不要翻译块类型名——**技术名必须能与规范逐字对照**。
- 不要在界面上出现第二个强调色。琥珀只有一个用途。
